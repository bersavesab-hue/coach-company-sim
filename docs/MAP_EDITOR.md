# 手机地图编辑器

入口：`tools/map-editor/index.html`

编辑器只负责生成正式地图内容，不维护第二套游戏地图逻辑。

## 支持内容

- 客运站：乡镇站、县级站、市级站、枢纽站
- 道路：乡道、县道、省道、国道、高速
- 普通路口节点
- 多折点道路
- 地图拖动与缩放
- 删除、撤销
- 导入已有 `world-map.v1.json`
- 加载本地山川河流背景图进行对照绘制
- 导出正式 `world-map.v1.json`

山川、河流、湖泊、海岸背景只用于视觉参照，不会进入导出的道路寻路数据。

## 接入游戏

1. 在手机浏览器打开编辑器。
2. 绘制客运站、路口与道路。
3. 点击“导出地图”。
4. 得到 `world-map.v1.json`。
5. 用导出的文件替换仓库中的 `src/content/map/world-map.v1.json`。
6. GitHub Actions 会执行 Core Check；APK 构建也会先执行正式地图校验。
7. 校验通过后，游戏启动时会自动通过 `WorldMapSeed` 构建唯一 `WorldGraph`，不需要修改游戏业务代码。

## 道路绘制

选择“画道路”后：

1. 点一个客运站或路口作为起点。
2. 在地图上点若干位置形成弯道。
3. 点另一个客运站或路口作为终点。
4. 点击“完成道路”。

道路长度会按编辑器世界坐标自动计算；道路速度由道路等级自动写入。
