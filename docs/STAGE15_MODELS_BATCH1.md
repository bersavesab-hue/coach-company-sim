# Stage 15：第一批 20 个正式基础车型

状态：Implemented

## 覆盖品牌与车系

- 江驰 V：4
- 江驰 M：4
- 宇盛 M：3
- 宇盛 C：3
- 中衡 C：3
- 金程 J：3

合计 20。

## 解锁节奏

第一批车型并非开局同时可买。

示例：
- 江驰 V5：Tier 1，开局可用
- 江驰 V6：第 2 天
- 江驰 V6L：第 3 天 + 声誉要求
- 江驰 V7：第 4 天 + 声誉 + 至少 1 辆车
- 宇盛 C8/C9/C10：Tier 2，并继续按车型细分开放时间

购买限制由 VehicleContentAccessService 在底层执行。

## 技术差异

江驰：
- 低能耗、低容量、小中型
- 保养周期偏短
- 磨损较快
- 面向低成本县域/乡镇经营

宇盛：
- 能耗更优
- 保养间隔更长
- 磨损更低
- 综合性能更均衡

中衡：
- 中巴运力较高
- 技术成本取向偏性价比
- 轮胎/动力磨损略高

金程：
- 能耗并非最低
- 保养间隔长
- 动力系统耐久
- 适合高里程县际/后续长途扩展

## Validator

正式内容包必须通过：
- ID 唯一
- 引用有效
- 参数正整数
- 能源储备小于总容量
- 解锁不能早于车系/Tier 下限
- 当前车型数不得超过车系 plannedModelCount
- 完全相同技术签名产生警告
- 批次 expectedModelCount 必须命中

当前批次要求 20 个车型并通过全部测试。
