# 国内式道路网形态样板

本文件定义地图视觉与拓扑的“自然路网”标准。它只约束道路形态，不引入真实地名、真实行政区或真实地图素材。

## 目标

地图应更接近国内导航地图的视觉组织：

- 高速是少量连续大走廊，而不是规则网格。
- 城市群之间存在多条不同等级的平行/斜向通道。
- 城市外围使用不规则环线、半环线和绕城通道。
- 互通通过主线节点和弧形匝道实现，不用十字交叉代替。
- 路网密度跟随城镇分布和地形变化，不平均铺满每块空白。

## 禁止模式

- 等距横线 + 等距竖线。
- 四点正方形城市环线。
- 国道/省道与高速完全重合。
- 为了填空而补一条没有交通目的的路。
- 两个城市之间永远使用一条几何直线。
- 所有交叉都自动成为可转向路口。

## 起步城市群

河源—永安—云州只借鉴国内城市群的道路组织方式，不复刻真实城市名称。

正式结构包括：

1. H02 东西向主高速。
2. H21 斜向高速。
3. H12 南北向高速。
4. N102 城镇串联国道。
5. N201 / N202 南北及斜向国道。
6. P820 / P821 / P822 三个不规则城市外环。
7. 城市站点通过 local_access / connector 接入外环。
8. 高速之间通过 ramp 转换。

## 扩展要求

后续新增城市群时先确定：
地形背景 → 城市与站点 → 高速走廊 → 国道 → 城市环线 → 省道 → 县乡支路。

禁止反过来先画规则路网再塞城市。
